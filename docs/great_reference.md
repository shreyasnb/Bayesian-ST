# GREAT implementation status

The author repository identified for comparison is
<https://gitlab.ethz.ch/asasfi/ST_for_sysID>.

The current implementation uses finite Grassmann gradient steps, an exponential
map, raw sliding-window or exponentially weighted covariance, and an explicit
proper-complex extension. Independent tests cover its gradient, exponential,
window updates, transport, and weighting.

Direct comparison with the author repository is still unverified. Access to
`gitlab.ethz.ch` was denied by the managed environment's outbound network policy.
