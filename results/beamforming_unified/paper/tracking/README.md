# Tracking evidence

The paper cohort uses fixed predeclared independent validation and test seed streams and is separate from the engineering quick profile. The general validation gate passed before held-out generation. All planned targets and their numerical flags are retained.

The experiment runner hashes scientific sources, configuration, task inputs, and JSON checkpoint results. The completed manifest hashes every retained CSV and NPZ artifact. Before using completed evidence, call `verify_component` from `lib.beamforming_validation` or use the figure readers, which call it.

Partial resume assumes that preassigned NPZ trajectory files in `trajectories/` remain intact. They are written separately from scalar JSON checkpoints; during an incomplete run, restoring a scalar checkpoint does not independently verify or recreate its NPZ file. If an incomplete run's trajectory files have been removed or changed, preserve the incomplete directory and rerun the same frozen protocol in a fresh output directory. Completed evidence is checked against artifact hashes and must not be silently repaired or overwritten.

`paired.csv` uses independent trajectories as the replicate. It retains the complete planned cohort, reports numerical-resolution counts separately, and marks missing endpoints. Its confidence intervals are exploratory pointwise paired Student intervals. Scalar posterior samples and fixed queries are not independent replicates. `risk_calibration.csv` first averages the fixed-query losses within each trajectory. `state_coverage_summary.csv` reports pointwise Wilson intervals without multiplicity adjustment; an observed interval excluding nominal is kept visible, not repaired by changing the test cohort.

The deterministic ULA path is a physical model mismatch for the stationary posterior and is not generated by the invariant stochastic transition. Forgetting changes the information/noise/drift tradeoff but does not establish frequentist calibration. The n=4 long stationary control is separate from the native n=8 short moving-array experiment. The nonvacuous modal certificate appears only in the long control here; invalid short-run conditions are retained as invalid.
