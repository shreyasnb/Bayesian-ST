# Matched-process evidence

This paper cohort uses the stated invariant proper-complex line transition and passive Gaussian snapshots with known sensor power, latent-signal power, and transition concentration. It is separate from the deterministic physical ULA experiment; no true transition concentration is assigned to that path.

The native n=8 and low-dimensional n=2 cohorts each contain 256 trajectories per concentration. Native expensive uncertainty reports use the predeclared first 32 trajectories per dimension/concentration; means, decisions, and prospective scores use all 256. The independent full-density CP1 filter is evaluated only on the predeclared first 32 n=2 trajectories per concentration. It is not a reference for an eight-element array. The same concentration has different overlap distributions in different dimensions.

The CP1 reference uses the complex Bloch sphere: its transition kernel is von Mises--Fisher with concentration kappa/2, and all spherical-harmonic degrees are included through the declared cutoff. Coarse/fine density, mean, continuous functional CDF/quantile and region-mass checks are retained in `reference_checks.csv`. `shape_checks.csv` measures the single-Bingham projection against this reference, a separate question from reference refinement. Predictive first-moment matching does not make the projected density or its tails exact.

Four of 192 reference-report targets fail the declared overall reference numerical guard. Diagnostic replay of exactly those targets, with identical frozen sources and budgets, identifies tiny negative spectral density mass: three coarse expansions fail while their fine expansion passes, and one fine expansion has negative mass 2.28e-9 above the 1e-9 guard. Their fine/coarse means and continuous scalar CDFs agree closely, but the overall unresolved flags remain. `reference_flag_diagnostics.json` records this diagnostic replay; it supplies no new cohort, filtering, clipping, refinement extension, repaired result, or inference endpoint.

`predictive_paired.csv` compares normalized pre-correction log scores after averaging over all times within each independent trajectory. Scores include Gaussian constants and identity-shift corrections. `paired.csv` keeps planned trajectory counts, explicit missing endpoints, and separate numerical-resolution counts. Its intervals are exploratory pointwise paired Student intervals. The tail/reference subset is distinct from the larger native mean cohort.

Experiment JSON checkpoints hash the scientific sources, configuration, task inputs and scalar results. Partial resume assumes that the separately written preassigned NPZ trajectory files remain intact; an incomplete scalar checkpoint does not verify or recreate its NPZ file. Preserve a manually damaged incomplete directory and rerun the same frozen protocol in a fresh output directory. Completed manifests hash every retained artifact; `verify_component` checks those hashes and source hashes before plotting.

Runtime columns time individual prediction, correction and report operations; they exclude some score/reference overhead and are not a fair end-to-end method speed comparison. The status wall time covers held-out generation and excludes beta validation and reference-development checks. Dedicated estimation/report-cost experiments provide the method-cost comparisons.
